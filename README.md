# 🧳 Bonvoyage

**Bonvoyage** — tes voyages, racontés. Une app web personnelle (PWA) pour tracer ses voyages sur une carte, y poser ses photos et vidéos, écrire le récit de chaque journée et le partager avec ses proches par un simple lien — sans qu'ils installent quoi que ce soit.

- 🗺️ Carte OpenStreetMap / CARTO, une couleur par journée
- 📍 Suivi GPS économe, balises ponctuelles, import et export GPX
- 📷 Photos compressées automatiquement, date et position lues dans la photo, légendes
- ✍️ Récit par journée, modifiable à tout moment
- 🔗 Page de partage publique par lien secret, commentaires des proches
- 📱 Installable sur iPhone, Android et Mac ; fonctionne hors ligne pour l'interface

Hébergement : GitHub Pages (app) + Supabase (données et photos), 100 % gratuit.
